# Cardiothoracic surgery notes (ST4 course and FRCS revision)

Offline-capable web app of personal revision notes. Rebuilt 19 November 2026.

Open: https://tm2525.github.io/Claude-apps/st4/

On iPad: open the link in Safari, tap Share, then "Add to Home Screen".

The page is generated: edit the sources in `st4-src/` (topic pages in `content/` and `md/`, drawings in `figs.py`, layout in `template.html`) and run `python3 st4-src/build.py` from the repository root.

Personal revision notes, not clinical guidance.
